# **App Name**: Vajra Reader

## Core Features:

- Multi-Language Text Display: Display the Vajrachhedika Sutra in Sanskrit (Devanagari and phonetic transliteration), Tibetan (and phonetic transliteration), and English.
- Persistent Language Selection: Retain user's reading position across language selections, maintaining the same section of text when the language is changed.
- Automatic Scrolling: Control scrolling speed of the text, with discrete plus and minus controls that persist on the screen; include pause/play functionality.
- Adjustable Text Size: Adjust text size using plus and minus controls that remain visible while reading.
- Searchable Glossary: Browse a searchable glossary of terms; highlight the term currently explored throughout the text in all languages.
- Donation Prompt: Display a discrete donation pop-up after 10 minutes of use, also accessible in the main menu.
- Clickable Index: Access a clickable index of sections (1-32) available in all languages; navigate directly to the selected section.

## Style Guidelines:

- Primary color: A subdued golden-brown (#A98E77), evoking a sense of warmth and tradition, yet staying modern.
- Background color: Very light beige (#FDFDFC), offering a clean and unobtrusive backdrop that supports readability.
- Accent color: Muted taupe (#D1C8C0), providing subtle contrast and highlighting key interactive elements.
- Body and headline font: 'EB Garamond', a serif font for elegant, literary, and crisp text, modern yet timeless.
- User Interface Font: 'Inter', a sans-serif font for buttons, menus, and functional UI elements, to give a clean, crisp appearance.
- Employ a modern and spacious layout with ample padding, providing an esthetically pleasing and luxurious experience.
- Subtle transitions for language changes and scrolling.
